# SMART-FINANCE-MANAGER
The Monthly Budget Planner is a Python-based project that helps users manage monthly income, track expenses, set budget limits, and monitor savings goals. It calculates total spending and remaining balance while using Python concepts such as OOP, functions, loops, conditions, lists and exception handling to manage finances efficiently.
1. **Introduction**
The Monthly Budget Planner is a Python-based project that helps users manage their monthly income, track daily expenses, control spending, and calculate savings. It allows users to enter their income and budget limit, add expenses under different categories, and view a summary of their financial activities.
2. **Objective**
The main objective of this project is to help users manage money effectively by tracking expenses, monitoring their remaining balance, and checking whether they have achieved their savings goals.
3. **Key Features**
- Income Management: Enter and manage monthly income.
- Expense Tracking: Add expenses with amount, date, category, and description.
- Budget Management: Set a monthly spending limit and monitor expenses.
- Category-wise Summary: View spending on food, shopping, travel, bills, and other categories.
- Balance Calculation: Calculate the remaining money after expenses.
- Savings Goal: Set a savings target and check whether it has been achieved.
- Transaction History: View previously entered expenses.
- Error Handling: Handle invalid inputs using exception handling.
4. **Python Concepts Used**
Python concept	Purpose
Variables and data types	Store income, expenses, and savings
Conditional statements	Check budget and savings status
Loops	Repeat the menu and process multiple expenses
Functions	Perform calculations and organize code
Lists and dictionaries	Store and organize expense information
Object-Oriented Programming (OOP)	Create classes and objects for transactions
Inheritance	Reuse common transaction properties
Encapsulation	Organize and manage transaction data
Exception handling	Handle invalid amounts and inputs
Date and time	Record transaction dates
Modules	Organize and reuse code

5.**How the Project Works**
1. Enter Monthly Income and Budget
2. Add Daily Expenses
3. Calculate Total Expenses
4. Check Remaining Balance and Savings
5. Display the Monthly Budget Summary


6. **Advantages**
- Helps users understand their spending habits.
- Reduces unnecessary expenses.
- Encourages regular savings.
- Provides a clear summary of monthly finances.
- Improves practical knowledge of Python programming.
7. **Conclusion**
The Monthly Budget Planner is a useful real-world Python project that helps users manage their income and expenses efficiently. It combines core Python concepts, object-oriented programming, loops, conditions, and exception handling in one application. This project is suitable for beginners who want to improve their Python programming skills through practical implementation.
